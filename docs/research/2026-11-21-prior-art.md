# Prior art: visual pipeline builders (2026-11-21)

## Takeaways

1. **Nobody does code-first, lossless editing of arbitrary Nextflow in the browser.**
   - Code Ocean's builder writes DSL1, and editing the code by hand switches the visual editor off.
   - DolphinNext keeps its own process database on a server.
   - Illumina ICA's graphical editor covers CWL only. Nextflow there is code-only.

   That leaves our gap: files as the source of truth, lossless import, typed syntax first, the official grammar, registry modules and plugins, no server.
2. **Two-way visual and code editing has been done well before, for an easier language.** Rabix Composer did it for CWL, which is YAML data. Nextflow is code, which is why ADRs 0004 and 0005 lean on the official grammar and on keeping unmodelled code. Rabix Composer has had no maintenance since 2021: a single-vendor editor goes stale once its sponsor moves on. Our mitigations are agent maintainability (ADR 0012) and language packs (ADR 0006).
3. **Graph-only builders lose power users.** Code Ocean's "unlock" is one-way. Our Code tab and Split view are the answer; keep them first-class.
4. **The layout is standard:** palette, canvas, properties (Elyra, Node-RED, Rabix, ICA). There's no need to invent UI conventions.
5. **Graph extraction from Nextflow already exists in research code.**
   - BioFlow-Insight is a useful reference for edge cases, but it is AGPL, so nothing can be copied into an MIT project.
   - Our own projection on the official AST stays the plan.

## Other visual workflow editors worth borrowing from

| Project | Lesson |
|---|---|
| [Rabix Composer](https://github.com/rabix/composer) (CWL, Apache-2.0) | Visual and code editors kept in sync, plus a form-based tool editor. Closest UX precedent. Unmaintained since 2021, and its graph library (cwl-svg) outlived the app |
| Galaxy workflow editor and [gxformat2](https://gxformat2.readthedocs.io/) | The most-used bioinformatics canvas. Format 2 stores node positions inside the workflow file; we keep them in a sidecar (ADR 0008) because Nextflow is code |
| [Elyra](https://elyra.readthedocs.io/) | The same three panes (palette, canvas, properties); double-click to open properties is a setting |
| Node-RED | Palette categories, the tabbed flows model, and a deployable JSON export |
| [Playbook Workflow Builder](https://playbook-workflow-builder.cloud/) (NIH) | Web builder for non-programmers over typed, semantically annotated steps. Types drive which connections are offered |
| BioDepot Workflow Builder | Docker-based desktop drag-and-drop; shows the cost of shipping a runtime |

## Visualisers and analysers

| Tool | Notes |
|---|---|
| [BioFlow-Insight](https://doi.org/10.1093/nargab/lqae092) | Python, AGPL. Rebuilds specification, dependency and process graphs from Nextflow source; also outputs metro-map JSON for MetroFlow. Useful test oracle for graph extraction on legacy code; can't be vendored |
| [nf-mapper](https://github.com/Skitionek/nf-mapper) | Nextflow to Mermaid gitGraph diagrams |
| Language server DAG preview | Official workflow graphs (Mermaid) in VS Code |
| [nf-metro](https://github.com/seqeralabs/nf-metro) and `manifest.diagram` | Nextflow 26.10 adds `manifest.diagram`, a relative path to a pipeline diagram (SVG preferred). nf-core recommends nf-metro (Python, MIT, v2.1.0): a Mermaid file with `%%metro` directives rendered to SVG. Its layout dependencies (lark, networkx, drawsvg) are pure Python; `av` and `resvg-py` are native, used for PNG and animation. **In v0.1:** the builder generates the `.mmd` and sets `manifest.diagram` (ADR 0013) |

## Names

- The project is personal, so no "Nextflow" in the name. Settled on **nf-builder** (open question Q1). Possible confusion: Nextflow's own Gradle plugin `io.nextflow.nf-build-plugin`, and `nextflow-io/schema-builder`.
- No established project is called "Nextflow Builder". Searches are crowded with unrelated "NextFlow" AI workflow builders, and `nextflow-io/schema-builder` exists.
- Ruled out:
  - "Nextflow Composer": StageNest's former name.
  - "Nextflow Studio": a CFD product from Nextflow Software, now part of Siemens. It would also clash with Seqera Studios.
