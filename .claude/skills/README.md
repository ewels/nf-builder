# Vendored Nextflow skills

Eight skills copied from [seqeralabs/nextflow-plugin](https://github.com/seqeralabs/nextflow-plugin) (Apache-2.0) at the commit in `UPSTREAM`. They live here because cloud sessions load the repo's `.claude/skills/` but don't install plugins declared in `.claude/settings.json`.

- Don't edit the skill folders. To update, run `.claude/skills/sync.sh` (or `sync.sh <commit>`) and commit the diff.
- Licence and attribution: `LICENSE-nextflow-plugin`, `NOTICE-nextflow-plugin`, `LICENSE-nextflow-agent-skills`.
- Some references link to plugin skills that aren't copied here, such as `launch-workflow`. Those links are dead.
- Temporary: F-705 removes this folder after v0.1.
