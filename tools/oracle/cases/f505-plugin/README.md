# Blank pipeline

A Nextflow pipeline with nothing in it yet.

- `main.nf` holds the entry workflow and the `params` block.
- `nextflow.config` holds the manifest and, later, profiles.
- `nextflow_schema.json` describes each parameter; add an entry when you add a parameter.

Add processes to the canvas to fill it in. Each one is saved in `modules/local/<name>/main.nf`.
