# nf-builder

A visual, browser-only builder for [Nextflow](https://nextflow.io) pipelines. Drag processes, workflows, operators and registry modules onto a canvas, wire them up, and get real, formatted Nextflow code. Start from scratch, from a template, or by importing a pipeline from GitHub or a zip. Projects stay in your browser; nothing is sent to a server.

**Status:** early development (milestone M0). The app will live at https://ewels.github.io/nf-builder/ (GitHub Pages, ADR 0040).
